# 来源与快照说明

- 上游仓库：`https://github.com/wduan1212-rgb/XZ-Design.git`
- 上游分支：`main`
- 快照基线提交：`345319e180eb1370e2b5e7b2d165a50f235e19e9`
- 项目内快照日期：`2026-07-16`

本目录来自上游工作区当时的完整功能快照。快照时上游工作区包含尚未提交的 UI、高清增强、
风格转换、局部编辑和画布交互更新；这些更新属于本次产品接入所需的实际功能，因此项目内副本
以当时工作区内容为准，而不是仅回退到基线提交。

项目内副本额外包含以下主平台适配：

1. 静态导出固定使用 `/XZ-Design` base path 和 hash 路由。
2. 嵌入模式从主平台 LocalStorage 读取 `dumate.token`，请求同源
   `/api/custom-canvas/*`。
3. 子应用 API Key 入口在嵌入模式隐藏。
4. Zustand 存储键按主平台成员 ID 分区。
5. 导出完成后向父窗口发送 `xingzhen-canvas / output-ready` 消息。
6. 风格转换、生成、增强和遮罩编辑统一经过主平台鉴权接口。

原上游工作区保持不变；本目录和 `vendor/infinite-canvas/` 已构成项目内部的源码与部署产物，
后续构建、测试和部署均不应再读取上游工作区。
