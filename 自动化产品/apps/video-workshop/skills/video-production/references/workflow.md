# 定制视频制作流程

## 三种输入路线

1. 选题：导演补全表达目标与口播，再进行分镜、配音、生成和剪辑。
2. 口播文本：默认保留用户原文，先合成或接入指定语音，再以真实音频时长重建镜头时间线。
3. 口播音频：先转写并获得时间戳，以原音频为主时间线，不重复生成配音。

## 附件角色

- `reference`：图片作为视频生成参考。
- `material`：图片或视频作为后期剪辑素材，按口播锚点插入。
- `narration`：音频作为成片主口播。
- `bgm`：音频作为背景音乐，并在人声出现时自动压低。
- `sfx`：音频作为局部音效，按口播锚点或镜头位置插入。
- `unused`：本次不使用。

用途不明确且不同选择会显著改变成片时，只追问一个决定性问题。用户已说明“图几、视频几或音频几”的用途时直接执行。

## 导演与时间线

- 先读完整口播，再按语义转折、情绪变化、信息密度与视觉连续性拆镜头。
- 生成片段时长只是供应商接口技术边界，不是创作模板。
- 最终剪辑以真实口播时长为准，生成镜头可裁切、补帧、转场或组合以覆盖整条时间线。
- 用户素材通过口播原文锚点定位；无锚点时由导演放入对应镜头的安全时间窗。

## 声音

- 口播始终是主声道。
- BGM 可按情绪与内容选择，也可以关闭；默认使用稳定选择，任务重试不随机更换。
- BGM 循环覆盖成片，并使用侧链压低或等效混音保护人声清晰度。
- 用户上传音效只在计划位置出现，不替换口播。

## 字幕与质检

- 字幕去除标点，按短语拆分，使用轻描边和克制动效。
- `9:16` 字幕位于画面下方三分之一安全区，其他画幅使用对应安全区。
- 交付前检查音视频时长、画幅、编码、音轨、字幕可读性、关键帧与素材覆盖。

## 平台迁移

- Skill 不携带 API Key、本机绝对路径或供应商密钥。
- BGM 通过资产接口获取 `asset_id / name / url`，本地目录仅是当前试验适配器。
- 附件角色和导演计划保持结构化，便于未来直接接入主平台任务队列与素材库。
