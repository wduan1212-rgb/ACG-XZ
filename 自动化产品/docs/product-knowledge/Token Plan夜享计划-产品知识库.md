## 二、夜享计划（主体事实）

### 2.1 权益机制
- 时段内，**套餐内**指定模型的 Tokens 消耗按 2 折计算。
- 机制本质是「加赠」：同一份订阅额度，在夜间时段可支撑约 5 倍的调用量。
  - 个人版表述：**1 Token 抵 5 Tokens**
  - 企业版表述：**1 积分 抵 5 积分**（企业版计量单位为 Credits 积分，非 Token）
- 生效范围：个人版 + 企业版全量有效订阅用户，无需申请、无需配置、订阅即享。

### 2.2 适用模型（重要，勿扩大）
夜间 2 折**仅明确覆盖以下 4 款模型**：

| # | 模型 |
|-|-|
| 1 | GLM-5.2 |
| 2 | DeepSeek-V4-Flash-0731 |
| 3 | DeepSeek-V4-Pro |
| 4 | DeepSeek-V4-Flash-0423 |

### 2.3 官方主打场景
- 让 Agent 在深夜跑通**长链路任务**
- 把白天没用完的调用额度**挪到夜间高倍率时段「回血」**
- 目标人群：习惯夜间攻坚的开发者、需要批量执行任务的团队

| 目标用户 | 个人开发者与 AI 重度用户 |
| 体系来源 | 在原有 **Coding Plan** 服务基础上完成体系化升级 |
| 产品体系 | 灵活额度、全场景通用、按需消耗的通用 Token 量包体系 |

### 4.2 四大产品特性

**① 统一 Token 抵扣，计费透明公平**
- 通用 Token 统一抵扣机制：**不区分模型倍率、不区分输入/输出/缓存命中**
- 所有调用均按实际 Token 消耗量统一扣减套餐额度
- 实现「小任务少消耗、大任务多消耗」的公平计费，消除复杂系数换算

**② 取消分层限流，高峰稳定可用**
- **完全取消**原 Coding Plan 的**三层滑动窗口限流体系**
- 套餐额度范围内按权益稳定提供服务，高峰时段可预期、不掉速
- 适配场景：Agent 长链路执行、批量代码生成、多仓库持续分析
- 用户价值：无需「攒请求」「等刷新」，工作流不被中途打断

**③ 旗舰模型自由切换**
- 模型间无缝切换，**无需额外付费、无需更换订阅，新模型上线即刻可用**

**④ 主流工具兼容 + 用量可控**
- 深度适配 Cursor、Windsurf、Cline 等 **10 余种**主流 AI Coding 工具与 Agent 框架
- 兼容 **OpenAI 与 Anthropic 双协议**，无需重构现有工作流
- 提供**个人版专属 API Key**，与后付费、企业版体系**完全隔离**
- 控制台内置用量统计模块：可实时查看各模型调用次数、Token 消耗明细、套餐剩余额度

## 七、接入方式（三步）

**步骤一：订阅 Token Plan**
进入 Token Plan 官网入口，选择套餐，提交并支付订单完成订阅。

**步骤二：获取 API Key 和 Base URL**（素材以个人版为例）
订阅完成后，在**「我的订阅」**模块获取专属 API Key；按 AI 工具支持的协议选择 Base URL：

| 协议 | Base URL（个人版） |
|-|-|
| OpenAI 兼容 | `https://qianfan.baidubce.com/v2/tokenplan/personal` |
| Anthropic 兼容 | `https://qianfan.baidubce.com/anthropic/tokenplan/personal` |

**步骤三：接入 AI 工具**
将 API Key 与 Base URL 配置到常用 AI 工具即可使用。配置时需将文档中的 API Key、model 入参、Base URL 替换为自己的信息。

**已兼容工具**：Cursor、Windsurf、Cline、Cherry Studio、Kilo CLI 等 **10 余种**主流 AI Coding 工具及智能体框架。
