# Dumate Studio v5 · 启动与架构说明

> 2026-06-12 · v5 全量重构版（旧版完整备份在 `_backup_v4/`，数据库独立、随时可回退）

## 启动

```bash
# 方式一：双击 start.command（推荐）
# 方式二：
node tools/serve.mjs 4188
# 浏览器打开 http://localhost:4188
```

⚠️ v5 使用 ES Modules，**不能双击 index.html 用 file:// 打开**，必须走本地 http 服务。

## v5 相对 v4 的变化

| 维度 | v4 | v5 |
|------|----|----|
| 代码组织 | 单文件 app.js 4257 行 | 34 个 ES Module（core / domain / api / agent / views / ui） |
| 任务模型 | 手动任务 + 快速任务两套互不相通 | 统一 `production` + 阶段状态机（脚本→分镜/成图→提示词→生成→剪辑→文案→审核→交付） |
| Agent | 日志气泡 + setInterval 盯进度，刷新即断 | 独立沉浸式工作台：会话持久化、结构化卡片（计划/进度/回传/审核/结果/失败）、事件驱动编排器、**刷新后批次自动接续** |
| 视频生成 | 同步假调用 | Job 队列 + ProviderAdapter（排队/进度/失败/重试/取消全状态），Mock 引擎模拟真实异步；接真 API 只需新增一个 adapter |
| 剪辑 | 基础时间轴 | 智能拼接（自动按片段排序 + 从口播铺字幕）+ 时间轴精修（排序/裁剪/**分割**/字幕拖拽/样式/SRT/撤销/缩放） |
| 存储 | IndexedDB 整包快照（生成中任务刷新即丢） | 分仓存储（8 个 store）+ 图片 Blob 化 + 自动迁移 v4 数据 + 导出/导入 |
| 措辞 | 发布 | **交付 / 定稿入库**（内部归档 + 供应商分发，无任何平台发布行为） |
| UI | 三套视觉混用 + emoji 图标 | 统一 tokens、SVG 图标、图标导航外壳、⌘K 命令面板、通知中心 |

## 信息架构

```
登录分流（创作端 / 供应商）
├── 总览        待办导向：待回传 / 渲染中 / 待审核 / 失败 / 待下载
├── Agent 工作台 沉浸式三栏：会话 | 对话流（结构化卡片）| 任务看板（流水线圆点）
├── 创作空间    账号面板 + 链路工具页（统一 stepper）
│   ├── 脚本   AI 按定位生成 / 行内编辑 / 优化方向重写
│   ├── 分镜·成图  统一参考图 + 站外整段提示词 + 拖拽回传（图片 API 未接入期的真实出图通道）
│   ├── 提示词  两段独立 15s 框架（数字人 / 无数字人）
│   ├── 生成台  即梦式对话流 · Job 驱动 · @资产 · 模拟引擎
│   ├── 剪辑   智能拼接 + CapCut 式时间轴
│   ├── 文案   爆款标题 + 正文
│   └── 审核   通过 / 驳回退回 / 交付入库
├── 资产库      全账号聚合 · 标签 · 拖拽上传
├── 交付中心    创作端视角（全链路回看）/ 供应商视角（表格 + 批量 zip）
└── 设置        能力-Key 档案 · 测试连接 · 数据导出/导入/清空
```

## 接真实视频 / 图片 API（预留好的口）

1. 在 `js/api/providers.js` 仿照文件底部的模板新增 adapter（实现 `submit / poll / cancel` 三个方法 + 字段映射）；
2. `registerProvider(...)` 注册，`activeProviderFor()` 会在设置页配置了对应 Key 后自动路由；
3. UI / 队列 / 重试 / Agent 编排零改动。

语言模型：内置 DeepSeek 直连（内部原型约定）；设置页保存"脚本/文案"类 Key 可覆盖 endpoint / key / model；CORS 受阻时 `python3 proxy.py` 后把 Provider 填 `http://localhost:8787/chat`。

## 数据与回退

- v5 数据库：`dumateStudioV5`（IndexedDB 分仓）；首次启动自动从旧库 `acgVideoTool` 迁移（账号 / 资产 / 历史交付 / 在制任务 / 快速批次），**旧库原样保留**。
- 回退方式：把 `_backup_v4/` 三件套复制回根目录即可（旧库数据未动过）。
- 设置页支持全量 JSON 导出 / 导入 / 清空。

## v5.1 增量（2026-06-12 下午）

**品牌**：全站换 ACG TV 标识（渐变描边播放三角 + 字标），开屏重做为霓虹舞台动效（光弧/光束/粒子 + 发光 Logo + 玻璃登录卡）。

**登录与权限**（前端口令校验，内部使用）：
- 管理员（默认口令 8888）：全功能 + 账号创建/编辑 + 设置（含改口令）
- 创作成员（6666）：批量/单号创作全流程，不可管账号、不可进设置
- 供应商（2222）：仅发布清单 —— 下载素材 + **回传发布链接**（回传后素材标记「已发布」，链路闭环）

**导航重命名**：首页 / 批量创作 / 单号创作 / 整体资产 / 发布清单 / 设置。

**素材号（无数字人）专属链路**：脚本（60-120s 长口播稿，按定位有深度/有梗）→ 生成口播音频（TTS 接口预留，未接入按 4.2 字/秒估时）→ **分镜工坊**（一体节点：每镜头一张卡 = 分镜图提示词 + 出图槽 + 视频提示词[自动带无口播/无BGM负面词] + 视频生成状态；站外模式为 ≤10 张/组提示词）→ 智能混剪（片段时长跟随口播 + 自动铺字幕 + 智能选配 BGM，音量恒低于口播，剪辑页可换曲/调音量）→ 文案 → 审核 → 交付。单镜头可随时重新生成，时间轴对应片段自动换绑。

**批量创作升级**：欢迎页三张固定流程模板卡（全部图文号出笔记 / 全部素材号全自动出片 / 全部真人号出口播视频）——主题每号随机（AI 按各自定位出题）、风格用账号自带「创作风格」（账号创建时设定）；素材号批次全程无需人工回传（站内 mock/真实 API 直跑到审核）。随机灵感每次真随机（LLM 按账号矩阵生成，离线兜底）+ 换一批按钮。会话支持重命名/删除，历史空会话自动清理。

**首页**：移除与左侧重复的 Agent 入口；底部新增**数据问答**（只读库内真实数据回答"昨天产出多少/供应商下载了多少/谁产量最高"等，不执行任何操作；无 LLM Key 时规则兜底直接算）。

**修复**：首页/资产库无法滚动（flex 链 min-height）、Agent 顶栏 logo 显示为白点（换为机器人头像）、空会话堆积。

⚠️ 语言模型 Key 已从代码移除：需在「设置 → 接入服务」保存一个「脚本/文案（语言模型）」Key 后，AI 起草/路由/数据问答才走真实模型；未配置时全部走本地模板与规则兜底，流程仍可完整演示。

## v5.2 增量（2026-06-13）

**登录改为成员账号制**（为上服务器做准备）：每人一个账号（用户名+口令+角色），管理员在「设置 → 成员账号」增删改。演示账号：管理员 admin/admin888、成员 editor/666666、供应商 supplier/222222。
- 权限：管理员（全功能+管账号/成员/设置）、创作成员（只走创作流程）、供应商（只进发布清单）。
- **创作互不干扰**：每人的批量/单号创作、会话、任务看板按 ownerId 隔离；**资产库与发布清单全员共享**。
- 资产全局共享、按上传先后顺序编号（M0001…），供应商端可见。

**素材号链路按需出图（核心智能）**：脚本生成时每镜头自动标 `ui`（含产品界面/logo/真实中文）和 `scene`（连贯分组）。分镜工坊把连贯镜头按场景合并成「分镜单元」：
- 含界面/logo/中文 → **图生视频**：先出分镜图提示词→出图/上传→视频提示词呼应图片。
- 纯场景 → **文生视频**：跳过出图，直接生成；同场景多镜头合并成一条多镜头视频提示词。
- 顶部统一参考图（所有需出图分镜共用 logo/产品界面）+ 每单元可单独加定制参考。批量创作里素材号自动识别 t2v/i2v，并提供统一参考图入口。

**素材号脚本**：加长到 12-18 镜头/60s+，口播强利他、有信息量；自动去掉"关注我/三连/下期见"等引导式结尾。

**任务看板**：按会话独立（不跨会话）；每条任务带类型标签（真人/素材/图文）；可删除单条任务或整批；整体改成左色条平铺式，更科技极简。会话聊天记录完全隔离。

**Agent 思考面板**：思考时显示带动效的小面板——逐条思考过程（读取上下文 → 识别意图 → 匹配账号 → 起草 x/n）+ 当前批次进度条，增强真实运作感。

**剪辑（素材号）**：声音轨面板——口播音频时长 + BGM 选择/换曲 + BGM 音量滑杆（恒低于口播）。
