## 当前架构

```text
index.html
├── js/core/       状态、路由、迁移、工具
├── js/domain/     账号、生产任务、资产、交付
├── js/api/        LLM、图片、视频、TTS 与任务适配
├── js/agent/      批量计划、会话、任务编排与任务板
├── js/views/      首页、单号、资产、草稿、发布、分析、语音、供应商
├── js/ui/         弹窗、图标、登录动效与通用交互增强
├── styles/        基础变量、业务页面、批量工作台与动效层
└── server/        FastAPI、持久化、上传与 provider 代理
```

核心任务模型为 `production`：

- 图文：图文创作台 -> 审核 -> 交付。
- 素材视频 / 真人视频：文案分镜 -> 智能混剪 -> 审核 -> 交付。
- 批量创作只负责选择账号、填写各账号自定义文案、参考图和启动批次；单号工作台负责具体生产与修正。

## 数据边界

- 本地运行态数据位于服务端数据库、上传目录和浏览器状态中，不属于静态代码。
- `.env.local`、服务器环境变量、API Key、认证缓存、数据库、上传文件、合成文件和日志不得提交 Git。
- 部署只能同步代码与静态资源，不得用本地空状态覆盖服务器账号、成员、资产、草稿、发布清单、分析数据或环境配置。
- 生产环境启动、停止、状态和数据排除规则见 `deploy/README.md`。

## 修改后的最低验证

```bash
git status --short
git diff --check
git branch --show-current

for file in $(find js -type f -name '*.js' -print); do
  node --check "$file"
done

curl -fsS http://127.0.0.1:8787/api/health
```

前端改动还必须使用真实浏览器验证受影响页面、交互、桌面和必要的移动端布局。只看代码或静态截图不算完整验收。
