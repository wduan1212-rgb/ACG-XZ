
也可以双击 Finder 中的 `start.command`。启动器会同时运行：

- 主平台：`0.0.0.0:8787`，浏览器与同源 API 入口。
- 视频工坊 sidecar：`127.0.0.1:8765`，只供主平台本机调用，不向局域网
  单独暴露。

浏览器入口为：

```text
http://127.0.0.1:8787/
```

共享局域网调试使用 `start-shared.command`。它仍只共享 `8787` 主平台，
`8765` 视频工坊保持回环访问。不要直接双击 `index.html`，当前前端使用
ES Modules，并依赖同源 `/api/*` 服务。

首次启动视频工坊时会在 `apps/video-workshop/.venv/` 安装独立依赖；
上传、项目、成片、BGM 和语音识别模型缓存保存在 `runtime/`，不会写进
子应用代码目录。退出 `8787` 主服务或按 `Ctrl+C` 后，启动器会同步结束
本次启动的 `8765` sidecar。

健康检查：

```bash
curl -fsS http://127.0.0.1:8787/api/health
curl -fsS http://127.0.0.1:8765/api/health
```

## 当前架构

```text
index.html
├── js/core/       状态、路由、迁移、工具
├── js/domain/     账号、生产任务、资产、交付
├── js/api/        LLM、图片、视频、TTS 与任务适配
├── js/agent/      批量计划、会话、任务编排与任务板
├── js/views/      首页、单号、资产、草稿、发布、分析、语音、供应商
├── js/ui/         弹窗、图标、登录动效与通用交互增强
├── styles/        基础变量、业务页面、批量工作台与动效层
├── vendor/        无限画布等服务器直接托管的静态子应用产物
├── apps/          视频工坊运行副本与无限画布可重建源码
├── runtime/       本地子应用项目、上传、成片、BGM 与模型缓存（不入 Git）
└── server/        主平台 FastAPI、持久化、上传与 provider 代理
```

核心任务模型为 `production`：

- 图文：图文创作台 -> 审核 -> 交付。
- 数字人账号：数字人制作 -> 智能混剪 -> 审核 -> 交付。
- 素材账号：信息流制作 -> 智能混剪 -> 审核 -> 交付。
- 批量创作只负责选择账号、填写各账号自定义文案、参考图和启动批次；单号工作台负责具体生产与修正。

## 数据边界

- 本地运行态数据位于服务端数据库、上传目录和浏览器状态中，不属于静态代码。
- `.env.local`、服务器环境变量、API Key、认证缓存、数据库、上传文件、合成文件和日志不得提交 Git。
- `runtime/` 与 `apps/video-workshop/.venv/` 属于本机运行数据，不得提交或
  用本地空目录覆盖服务器持久卷。
- 部署只能同步代码与静态资源，不得用本地空状态覆盖服务器账号、成员、资产、草稿、发布清单、分析数据或环境配置。
- 生产环境启动、停止、状态和数据排除规则见 `deploy/README.md`。
